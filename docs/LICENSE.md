[MVTec Anomaly Detection dataset (MVTec AD)](https://www.mvtec.com/company/research/datasets/mvtec-ad)
by MVTec Software GmbH, with anomaly heatmaps produced by this project.

itself: non-commercial use only, with attribution, and adaptations must use the same licence.

Paul Bergmann, Michael Fauser, David Sattlegger, Carsten Steger: "MVTec AD — A Comprehensive
Real-World Dataset for Unsupervised Anomaly Detection", CVPR 2019.

The rest of the repository does not contain MVTec images or models trained on them.
